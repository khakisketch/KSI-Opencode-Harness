# Native Goal (선택)

일반 개발은 Goal 없이 조사·구현·검증·수정까지 진행합니다. 별도 장기 반복이 필요할 때만 OpenCode 내장 기능을 선택합니다.

```text
/goal 승인된 범위에서 구현·검증하고, 기존 데이터를 보존하며 실제 차단을 보고해줘.
/goal pause
/goal resume
/goal clear
```

같은 세션에서 사용하며 기존 목표·승인 범위·추가 모델 비용을 확인하세요. 일시정지·삭제와 현재 실행 중단은 다릅니다. 사용자 중단 뒤 임의로 재개하지 않습니다.

**KSI의 Lead Goal 자동 시작 계획과 상태 전달 플러그인은 제거했습니다.** Native Goal 자체나 일반 자식 위임을 제거한 것이 아닙니다. 부모 목표가 자식에 자동 상속된다고 가정하지 말고 필요한 목표·제약을 위임문으로 전달합니다.

Goal 완료 표시와 자식 도구 완료는 검사 성공·제품 수용이 아닙니다. 실제 결과를 별도로 확인합니다.
