# OpenSpec — 퇴역한 명세·변경·생성물 기록

2026-10-26에 활성 작업 흐름에서 제거했습니다. 이 디렉터리는 **역사·출처**이며,
안의 SHALL·역할명·명령·계획 중단 지시는 현행 실행 지침이 아닙니다. 자동 발견 경로에
복사하거나 이 기록을 근거로 OpenSpec을 초기화하지 않습니다.

- `openspec/`: 당시 메인 명세와 세 변경의 원본. 미완료 과제는 완료 처리하지 않았습니다.
- `integration/`: 당시 명령 6개·스킬 6개의 원본. Native 발견 경로 밖에 보존합니다.
- 당시 채택·검토 기록: [`../../openspec-and-skills.md`](../../openspec-and-skills.md).

현재 책임·안전·검증 계약은 루트 README, `global/`, 설정과 실제 실행 테스트가 소유합니다.
새 변경은 기존 프로젝트 정본·결정 기록·코드·실행 증거를 갱신하며 별도 프레임워크를
요구하지 않습니다. 현행 미검증 사항은 [`../../engineer-routing-validation.md`](../../engineer-routing-validation.md)를 봅니다.
