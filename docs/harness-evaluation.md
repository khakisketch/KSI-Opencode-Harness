# 하네스의 실제 과업 평가

역할·권한·설치·도구 검사는 필요한 기반이지만 사용자 경험의 개선을 증명하지 않습니다.
이 문서는 비교 방법이며 결과 보고서나 새로운 제품 목표 정본이 아닙니다.

## 비교 조건

- 현재 OpenCode와 개선 OpenCode는 같은 기준 코드·승인된 미커밋 변경·모델·추론 수준·예산·권한으로 새 세션에서 비교합니다.
- Codex 비교도 같은 기준과 요청을 사용하되 모델·도구·서버 측 조건을 맞출 수 없는 차이를 명시합니다. 이름이 같은 모델만으로 동일 조건이라 하지 않습니다.
- 각 실행은 독립된 작업본·로컬 테스트 데이터·포트·증거 위치를 사용합니다. 앞선 후보의 수정 결과를 다음 후보의 출발점으로 쓰지 않습니다.
- 시작 전에 사용자 과업·보존 조건·검증법을 정하고 실패·중단·시간 초과도 남깁니다. 좋은 사례만 고르지 않습니다.
- 모델 변경, 위임 정책, 시각 도구 수정, 압축 설정은 가능한 한 따로 비교합니다. 현재 제품이나 운영 DB를 실험 대상으로 자동 선택하지 않습니다.

## 대표 과업

| 유형 | 한 번의 요청에 포함할 결과 | 관찰할 실패 |
| --- | --- | --- |
| 버그 수정 | 재현 → 수정 → 관련 회귀 및 원래 재현 확인 | 설명이나 첫 수정 뒤 조기 종료 |
| 기능 개발 | 주요 사용자 흐름·권한·재시도·기존 데이터 보존까지 연결 | 하위 작업 완료를 전체 완료로 오인 |
| UI 단순화 | 채택한 방향으로 수정하고 실제 데스크톱·모바일 화면과 주요 행동 확인 | 사용자가 거부한 카드·설명을 다시 추가 |
| 병행 변경 | 다른 변경 보존, 독립 작업 진행, 통합 직전 재대조 | 무조건 중단·덮어쓰기·미커밋 기준 누락 |
| 이어가기 | 위임 또는 압축 뒤 목표·정정·미완료를 유지하고 재개 | 같은 요구 재질문·진행 상태 초기화 |
| 도구 복구 | 승인된 외부 합성 캡처 검토, 불허 파일은 거부 | 반복 실패·경계 우회·영수증 없는 검토를 영수증으로 표시 |

## 결과 기록

기존 검증 문서나 비공개 실행 기록에 아래 항목만 간결하게 남깁니다. 새로운 전역 제품 원장을 만들지 않습니다.

1. **조건:** 코드 기준과 로컬 변경 식별, 실제 모델·추론 수준, 실행 환경과 예산, 비교 불가능한 차이.
2. **결과:** 완료 조건별 실제 구현·검증·미검증·차단. 테스트 성공과 제품 수용은 구분.
3. **사용자 부담:** 재촉, 같은 설명 반복, 방향 정정, 불필요한 확인 질문 횟수. 정당한 권한·제품 결정 질문은 따로 분류.
4. **복구와 보존:** 도구 실패/충돌 뒤 진행, 승인 범위·기존 작업·거부한 방향 유지 여부.
5. **비용:** 첫 검토 가능한 결과까지의 시간, 총 시간, 토큰/과금과 단위, 검토·재작업 비용. 모르면 unknown.

먼저 요구 충족과 안전을 통과해야 합니다. 자식 수·호출 수·테스트 수가 줄었다는 이유만으로 우수하다고 판정하지 않습니다.
소수의 합성 사례는 일반적인 Codex 대비 우위나 실제 제품 품질의 증거가 아닙니다.

기존 검증 문서나 허용된 비공개 기록이면 충분하며 전용 JSON 도구를 요구하지 않습니다.
실모델 실행은 별도 사용량을 소비하며 승인된 제공자·자료 범위 안에서만 수행합니다.
