# 프로젝트 AGENTS.md — 선택적 진입점 예시

[전역 공통 원칙](../global/AGENTS.md)은 복제하지 않습니다. 기존 프로젝트 지도가 있으면
그것을 보완하고, 아래 예시를 새 문서 세트나 필수 읽기 목록으로 적용하지 않습니다.
경로·권위·명령은 실제 저장소를 확인해 채우며, 한 문서가 여러 행을 맡아도 됩니다.

```markdown
# <프로젝트 이름> — 개발 진입점

<누가 어떤 환경에서 무엇을 끝내는 제품인지 한두 문장>

## 현행 정본 지도

| 찾을 내용 | 기존 정본 / 해당 절 | 소유 범위·충돌 시 기준 |
| --- | --- | --- |
| 제품 목적·범위 | <기존 경로> | <프로젝트의 현재 권위> |
| 사용자 업무·화면 책임 | <기존 경로> | <흐름·화면별 소유 문서> |
| 시스템·데이터·계약 | <기존 경로> | <아키텍처·스키마·불변식> |
| 구현·검증 상태 | <기존 원장 경로> | <현재 요약·증거 위치> |

## 실행·검증 진입점

- 관련 코드·실행 환경: <실제 경로 / 로컬 실행 명령>
- 검증: <과업에 맞게 선택할 테스트 / 렌더 / 실기 확인 경로>

## 프로젝트 고유 경계

<보호할 공유 자원·실기 승인 범위 등 전역 원칙에 없는 프로젝트 사실만>
```

위 표의 순서는 독서 순서가 아닙니다. 없는 정본을 만들어 채우거나, 기존 승인 계약을
이 예시의 분류에 맞춰 바꾸지 않습니다. 자세한 책임·원장 예시는
[프로젝트 지식과 상태 관리](../docs/project-knowledge.md)를 참고할 수 있습니다.
