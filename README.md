# KSI OpenCode Harness

제품 완성을 위한 선택형 최소 지침입니다. 별도 실행 프레임워크나 설치기는 제공하지 않습니다.

[지침 예시](examples/project-AGENTS.md)가 필요한 경우에만 기존 전역 또는 프로젝트
`AGENTS.md` 한 곳에 적용하세요. 이 지침은 기본 에이전트·모델·권한·실행 구조를 변경하지 않습니다.

제품별 요구사항과 검증은 해당 프로젝트의 기존 문서·테스트·CI에서 관리합니다.
실행 기능과 설정은 [OpenCode V2 공식 문서](https://opencode.ai/v2/docs/)를 따릅니다.

> 이전 npm beta 설치기는 레거시입니다. 현재 구성에 설치하거나 재적용하지 마세요.
